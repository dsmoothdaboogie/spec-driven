# AGENTS.md (ui-app)

## Commands
- Dev: `npm run dev`
- Build: `npm run build`
- Tests: `npm test`
- Lint: `npm run lint`
- Typecheck: `npm run typecheck`

## Contract Handling
- Import types from `@org/contracts` or a submodule `contracts/openapi.yaml`.
- Regenerate typed clients on contract bump.
