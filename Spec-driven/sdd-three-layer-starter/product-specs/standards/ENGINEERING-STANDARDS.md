# Engineering Standards (Excerpt)
- Languages: TypeScript for UI and Node services.
- Formatting & Style: ESLint + Prettier defaults; CI-enforced.
- Testing: Vitest/Jest; write contract tests against OpenAPI.
- Observability: Metrics, logs, traces required for new services.
- Security: OWASP ASVS L2, no secrets in source, dependency review.
- Accessibility: WCAG 2.2 AA for UI.
