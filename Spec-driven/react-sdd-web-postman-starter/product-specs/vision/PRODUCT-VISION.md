# Product Vision — Web Postman (Browser-based API Client)

Deliver a **lightweight, secure, browser-first** alternative to Postman that runs inside the corporate network with zero desktop installs.

**Success Metrics**
- TTS (time-to-send) first request < 60s for new users.
- 90th percentile request round-trip from UI < 500ms (intranet targets).
- Reduce external-tool exception requests by 80% for API debugging use-cases.
